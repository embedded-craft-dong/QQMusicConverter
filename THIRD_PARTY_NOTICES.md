## Port provenance

`qmc_core.py` is a Python port/adaptation, not an unmodified upstream file.
It retains TEA, QMC map and segmented stream algorithms; this release adds
cooperative cancellation/progress callbacks. The optional Windows login adapter
has explicit scan budgets, time checks, session reuse and opt-in UI disclosure.

Upstream reference reviewed for this release:
`ownlight6/qmc-decoder` commit `293bdc262a2f59ab6d45fa7149ce6c3f4ebfba54`.
This identifies the reviewed reference, not a verified historical base of every
line from the earlier local port. `tc_tea` declares MIT OR Apache-2.0; its LICENSE
file is included verbatim in `licenses/tc_tea-LICENSE.txt`.

## Native library sources and rebuilding

The soundfile 0.13.1 wheel supplies libsndfile 1.2.2 and native codec support.
Its native-library submodule is
https://github.com/bastibe/libsndfile-binaries/tree/a3e6f9769d0c7e91d2d036cf0fdbe5b4bbf18b87
which provides the native build recipe, dependency versions and upstream sources.
Runtime DLLs are bundled unmodified from the installed wheel.

The Python-SoXR wheel bundles libsoxr. Corresponding wrapper, native source references,
and build configuration are at https://github.com/dofuuz/python-soxr/tree/v1.1.0 .
Its libsoxr and PFFFT notices are copied from the wheel into `licenses/soxr/`.
Pillow's wheel license file includes notices for its bundled image libraries.
To replace these native components, build the dependency from its upstream source,
install the rebuilt wheel into the build environment, and rebuild this application.

To use a modified library, rebuild it using the upstream recipe, replace the
library in your build environment's `_soundfile_data` package, then rebuild the
application with `scripts/build_release.py`. The application source imposes no
signature or library-hash restriction. The complete application build instructions
are in README.md. Preserve third-party notices when redistributing modified builds.

This source archive contains the application's corresponding source, not full
source copies of Python and every external dependency. Their sources and native
build recipe are linked above; assess the requirements of your chosen binary
distribution method before redistributing a different bundle.
