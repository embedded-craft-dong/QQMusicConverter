# 发行验证记录

[English](RELEASE_CHECKS.md) | **简体中文**

## 0.3.0-beta.1

- Windows x64 / Python 3.12.14 下 34 项离线回归通过，使用合成音频、图片和歌词。
- WAV 检查涵盖 44.1 kHz 单声道、48/96 kHz 双声道输入，以及输出参数、时长、音高、跨块连续性、抗混叠和取消保护。
- GUI 检查涵盖转换选中、自动素材、独立失败重试、歌词偏移、同名 LRC 保护、队列原文件保护，以及 100% / 125% / 150% / 200% 缩放布局。
- 在线验证成功获取歌曲信息、专辑 JPG 和 118 行带时间戳的 LRC，统一输出名称正确。真实素材未包含在仓库及发行包中。
- EXE 界面检查涵盖主窗口、居中设置弹窗、标签页、在线歌词预览和完成后控件恢复。
- 便携 EXE 隔离自测通过：复制至不含源码的目录，清除 Python 环境变量，PATH 仅保留系统目录，验证 MP3、WAV、内嵌封面、LRC 和 Tk。
- [发行提交的 Windows CI 已通过](https://github.com/embedded-craft-dong/QQMusicConverter/actions/runs/41196381480)，包括回归测试、EXE 构建和便携运行自测。
- 已发布的 4 个附件均核对 SHA-256；发行标签对应通过测试的提交。

### 尚未覆盖的环境

尚未在独立、未安装 Python 的 Windows 10/11 实体电脑上完成验收。隔离自测与 CI 不覆盖全部硬件环境。
在线验证不保证所有歌曲始终可用。加密音频登录适配沿用既有实现，不代表已验证所有 QQ 音乐客户端版本。

## 0.1.0-beta.1

首个公开测试版通过 14 项离线测试和本机 EXE 检查，涵盖合成 OGG/WAV 与 musicex/QMC2 转换、完整解码、TEA 向量、损坏文件及错误密钥检测、防覆盖、取消清理、模拟会话复用、GUI 重试、设置保存与多档缩放。

该版本 Windows CI 也已通过。这些结果不代表兼容所有 Windows 安装环境和 QQ 音乐客户端；独立干净系统及更广泛的硬件、辅助功能验证仍未覆盖。
